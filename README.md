# Lachesis Zend

> [!WARNING]
> ## Archived
> Lachesis Zend is no longer maintained and will receive no further releases.
> It is a Zend DB and ServiceManager integration retained only for existing
> installations. Use the database and dependency-injection facilities of your
> current framework or a maintained data-access library for new applications.

## Historical package

This repository is retained to preserve the source and Composer package for
existing users. It is not compatible with current PHP or framework releases.
